delta-042 · 2026-08-10

Apresentação deixa de ser um tipo de diagrama e vira um modo

Qualquer categoria do perfil pode pedir acabamento para a alta gestão, sem abandonar a ferramenta correta dela.

Contexto Fluxos Decisões

Contexto

Documentação que vai a cliente, gestão ou stakeholder precisa sair bem renderizada. Até aqui, apresentacao era o sétimo tipo de diagrama do perfil do projeto — irmão de arquitetura, modelo de dados e fluxos.

Isso tornava impossível pedir “a arquitetura com acabamento”: só dava para pedir “um diagrama da categoria apresentação”, o que forçava escolher entre a ferramenta correta da categoria e o acabamento. Acabamento é um eixo perpendicular à categoria, não um valor dela.

Fluxos

Decisões

  • Apresentação virou uma marca, não uma categoriaCada artefato do perfil ganha apresentacao: true. A ferramenta continua seguindo a categoria; a marca só diz se aquele artefato também sai com acabamento.
  • O motor padrão não depende de pluginO HTML é escrito seguindo a regra canônica do framework. O plugin de terceiro continua disponível para quem o quiser, mas saiu do caminho padrão.
  • Um arquivo por delta, com âncorasQuem lê não navega pasta. A arquitetura avulsa se manda por link direto para a seção, sem um segundo arquivo existir.
  • O documento assinável não foi tocadoO entregável congelado continua saindo pelo mesmo pipeline de sempre. Esta camada é apresentação, nunca contrato.
